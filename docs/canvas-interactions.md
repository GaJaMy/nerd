# 캔버스 중심 편집 요구사항

## 사용자 요청

1. 캔버스를 어두운 색으로 변경합니다.
2. 테이블은 즉시 생성 버튼 대신 마우스로 영역을 그려 생성합니다.
3. 이름 표시 모드는 **논리명 / 물리명 / 논리·물리**를 제공합니다.
4. 테이블과 컬럼의 논리명·물리명은 동등한 별도 칸에 표시합니다. 논리명이 왼쪽, 물리명이 오른쪽이며 레이블로 구분합니다. 한쪽을 작은 보조 이름으로 배치하지 않습니다.
5. 캔버스에 그려진 테이블에서 테이블·컬럼의 논리명과 물리명을 직접 수정할 수 있습니다.
6. 테이블 적용 버튼을 제거합니다. 유효한 입력은 즉시 모델·패널·검색·DDL에 반영합니다.
7. 컬럼은 오른쪽 패널의 추가 버튼 대신 테이블 하단에 마우스를 올리면 나타나는 **+** 버튼으로 추가합니다.
8. 오른쪽 패널에서 관계 연결을 시작한 뒤 캔버스의 두 테이블을 차례로 클릭합니다.

## 상호작용 세부 규칙

### 그리기와 화면 이동

- 기본 모드는 테이블 그리기입니다. 빈 캔버스에서 왼쪽 버튼으로 드래그하면 미리보기 사각형을 표시하고 놓은 위치에 테이블을 생성합니다. 반대 방향으로 그려도 동일하게 동작합니다.
- 단순 클릭이나 8px 미만의 드래그는 테이블을 생성하지 않습니다. 좌표와 크기는 현재 pan/zoom을 반영한 캔버스 좌표로 변환합니다.
- 테이블은 최소 너비 360px, 최소 높이 140px로 생성합니다. 드로잉 크기는 최소 표시 크기이며 컬럼이 늘어나면 내용에 맞게 높이가 늘어납니다.
- 이동 모드를 선택하거나 마우스 가운데/오른쪽 버튼으로 빈 공간을 드래그하면 화면이 이동합니다. 휠과 캔버스 컨트롤로 확대·축소합니다.
- Escape, 포인터 취소, 모드 변경 시 진행 중 드로잉을 취소합니다. 입력창·노드·컨트롤 위에서는 새 테이블을 그리지 않습니다.

### 이름 편집과 표시

- 기본 표시 모드는 논리·물리입니다. 단일 표시 모드에서도 해당 칸이 논리명인지 물리명인지 분명하게 표시합니다.
- 비어 있는 논리명 칸은 입력 힌트를 제공합니다. 선택·검색을 위한 테이블 식별 정보는 유지합니다.
- 유효한 이름은 입력 즉시 반영합니다. 잘못된 물리명, 중복 이름, IME 조합 중 문자열은 입력 초안으로 유지하고 오류를 안내합니다. 유효하지 않은 초안으로 모델을 덮어쓰지 않습니다.
- Escape는 초안을 취소합니다. 다른 편집 위치에서 유효한 값이 변경되면 캔버스와 패널이 동기화됩니다. 입력창 조작은 노드 드래그·그리기를 발생시키지 않습니다.
- 이번 변경에서 즉시 반영 대상은 테이블 메타데이터와 캔버스의 테이블·컬럼 이름입니다. 오른쪽 패널의 컬럼 타입 등 상세 편집, PK 적용, 관계 매핑 확정은 기존 검증 단위를 유지합니다.

### 컬럼 추가

- 테이블 하단의 추가 영역에 hover하거나 키보드 focus가 들어오면 + 버튼을 표시합니다. 터치 환경에서는 항상 접근 가능합니다.
- 클릭하면 해당 테이블에 기본 BIGINT/NULL 허용 컬럼을 하나 추가합니다. 대소문자 중복을 피하는 기본 물리명을 생성하고 즉시 캔버스와 패널에 반영합니다.

### 관계 연결

- 오른쪽 **관계 연결** 버튼 → FK 소유 테이블 클릭 → 참조 대상 테이블 클릭 순서입니다. 현재 단계와 선택한 테이블을 안내합니다.
- 두 테이블을 선택하면 오른쪽 패널에서 기존 PK 순서에 맞춰 FK 컬럼 매핑·관계 종류를 확정합니다. 두 번 클릭만으로 컬럼 매핑을 추측하거나 새 컬럼을 자동 생성하지 않습니다.
- 같은 테이블을 두 번 선택하면 자기 참조 관계를 구성할 수 있습니다. Escape 또는 취소 버튼은 선택 과정을 취소합니다.
- 관계 선택 중에는 테이블 그리기와 캔버스 이름 편집·컬럼 추가를 잠시 막고 클릭을 테이블 선택에 사용합니다. 기존 관계의 끝점을 변경할 때도 두 테이블 다시 선택을 사용합니다.
- 선택한 테이블이 삭제되거나 숨겨지면 진행 중 연결을 취소합니다. 기존 FK 타입·복합 매핑·참조 키 검증은 유지합니다.

## 완료 기록

2026-09-16 기준 위 8개 요구사항과 0–6번 작업을 완료했습니다.

- 문서를 먼저 갱신하고 재독한 뒤 작업 순서대로 구현·검증·커밋했습니다.
- 단위·컴포넌트 테스트 34개, Chromium E2E 7개가 통과했습니다. 드로잉과 취소, 이름 편집·IME·동기화, 복합 관계·자기 참조, 관계 끝점 재선택, 터치 컬럼 추가를 검증합니다.
- 포맷·린트·타입 검사, Knip, 프로덕션 빌드가 통과했습니다. 데스크톱과 좁은 화면의 브라우저 캡처를 확인했습니다.
- MySQL DDL은 순수 함수와 다운로드 결과를 검증했습니다. 실제 MySQL 서버 실행은 검증 범위에 포함하지 않았습니다.
